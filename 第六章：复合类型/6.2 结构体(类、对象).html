6.2 结构体(类、对象)

上一节我们用枚举给一组整数起了名字。这一节更进一步：把好几个不同类型的数据，打包成一个整体。

还记得第六章开头说的那个游戏吗？一个 NPC，有血条（整数）、有名字（一串字符）、有位置（两个小数）……这些变量东一个西一个地散在代码里，代码维护起来非常麻烦。

数组倒是能装一堆，但它只能装同一种类型。

想把不同类型的变量捆在一起，就要用到结构体(也是我们常说的对象)。

class基本语法#

在 C++ 里，把不同类型的数据打包成一个整体，有两种几乎一模一样的写法：class 和 struct。这俩几乎一样，我们先了解class。

基础语法如下：

class 类名 {
	成员;
	成员;
	...
};

几个案例：

class Student {
public:
	int age;		// 年龄，整数
	int score;		// 分数，整数
	char name[20];	// 名字，字符数组
};

你可能注意到那个 public: 了。别慌，它的意思是下面的成员全部公开，谁都可以访问使用。class 的成员默认是“私有”的（外面访问不到），所以要先写一行 public: 。详细的访问控制在下一节讲解，这里你只要记住：用 class，记得先写 public:。

成员#

花括号里写的这些东西，就是这个结构体的成员。成员分三种：成员变量和成员函数还有成员类(又称嵌套类)。

成员变量#

成员变量就是结构体里装的变量，声明方式跟普通变量一样。上面那个 Student 里的 age、score、name 都是成员变量。

声明一个对象，然后读写它的成员变量，看看效果：

#include <iostream>

class Student {
public:
	int age;		// 年龄，整数
	int score;		// 分数，整数
};

int main(){
	Student s;					// 声明一个 Student 类型的对象，名字叫 s
	s.age = 18;					// 用点号 . 访问成员，给 age 赋值
	s.score = 100;				// 给 score 赋值
	std::cout << s.age << " " << s.score;	// 输出两个成员
	return 0;
}

运行结果：

18 100

Student s; 声明了一个Student 类型的变量，也就是一个对象实例。访问它的成员用点号 .

成员函数#

成员函数就是写在结构体里面的函数。它最大的方便之处：在函数里面，可以直接用这个结构体的成员变量，不用写 s. 前缀

#include <iostream>

class Student {
public:
	int age;			// 年龄，整数

	int getAge(){		// 成员函数：把 age 还回去
		return age;		// 直接写 age，不用写 s.age
	}
};

int main(){
	Student s;
	s.age = 18;
	std::cout << s.getAge();	// 调用成员函数，输出 18
	return 0;
}

运行结果：

18

成员类#

成员类只是把一个类的写在了另一个类里，实际上与不作成员类，只有前面多一个类名的区别。

语法就是把一个完整的类塞进外层类里：

class 外层类名 {
public:		// class 记得写，struct 不用
	class 内层类名 {	// 也可以用 struct
		成员;
	};
	内层类名 成员变量;	// 想要有这个类型的成员变量，还是需要自己再声明
};

还是拿 NPC 举例。NPC 有个位置，位置本身是 x、y 两个整数，这种小类型就适合嵌进去：

#include <iostream>

class NPC {
public:
	struct Pos {		// 嵌套结构体：位置
		int x;
		int y;
	};
	int hp;
	Pos pos;			// 用嵌套类型声明成员变量
};

int main(){
	NPC n;
	n.hp = 100;
	n.pos.x = 3;
	n.pos.y = 5;
	std::cout << n.hp << " " << n.pos.x << " " << n.pos.y;
	return 0;
}

运行结果：

100 3 5

注意 Pos 这个类型名现在在 NPC 类里面了，在外面想要声明需要用 NPC::Pos。那两个冒号叫作用域解析，读作“NPC 里面的 Pos”。所以外面直接写 Pos p; 是编译不过的：

int main(){
	Pos p;		// 报错：外面看不到 NPC 里的 Pos
	p.x = 3;
	return 0;
}

编译报错：

error: 'Pos' was not declared in this scope

改成 NPC::Pos p; 就是我们想要的东西了。

这里有个最容易误会的地方：成员类不是成员。在 NPC 里写一段 Pos 的定义，不等于每个 NPC 对象里都塞了一个 Pos，要Pos类型的成员要再声明变量 Pos pos;。

用 sizeof 试试就知道了：

#include <iostream>

class A {
public:
	struct Pos {
		int x;
		int y;
	};
};

class B {
public:
	struct Pos {
		int x;
		int y;
	};
	Pos pos;
};

int main(){
	std::cout << sizeof(A) << " " << sizeof(B);
	return 0;
}

运行结果：

1 8

A 里的 1 是因为：一个成员都没有的类，sizeof 是 1（跟 Pos 没关系）

B 占用的 8 字节才是 x、y 两个 int 的大小。所以嵌套只是名字上的包含，内存上毫无关系。

顺着这条再说一句：嵌套类里也直接摸不到外层类的成员，因为它根本不知道自己属于哪个外层对象：

class NPC {
	int hp;
public:
	struct Pos {
		int get(){
			return hp;	// 报错：哪个 NPC 的 hp？
		}
	};
};

编译报错：

error: invalid use of non-static data member 'NPC::hp'

报错说的是“非静态数据成员”

实在需要，可以把外层对象当参数传进去就行（5.4 的引用传参正好干这个）。

C 里也能在 struct 里写 struct，但他不需要::，写嵌套和不嵌套没有任何区别：

#include <stdio.h>

struct NPC {
	struct Pos {		// 嵌套声明一个结构体
		int x;
		int y;
	};
	int hp;
};

int main(){
	struct Pos p;		// C 里写 struct Pos 就行，没有 NPC::
	p.x = 3;
	printf("%d", p.x);
	return 0;
}

运行结果：

3

嵌套适合只给自己用的小类型（位置、链表节点这种），能少占一个名字。但嵌套一深，用的时候就成了 A::B::C 一长串，那还不如写在外边的代码好读一点。

访问成员：点和箭头#

访问成员要分两种情况：对象是普通对象，就用点号 .；对象是指针，那就要用箭头。

调用指针成员的符号不是.而是→

举个指针的例子：

#include <iostream>

class Student {
public:
	int age;
};

int main(){
	Student s;			// 普通对象
	Student* p = &s;	// 指向 s 的指针（4.2 学过 & 取地址）

	s.age = 18;			// 普通对象用点号 .
	p->age = 20;		// 指针用箭头 ->
	std::cout << s.age;	// 输出 20，因为 p 和 &s 指向同一块内存
	return 0;
}

运行结果：

20

其实 p->age 就是 (*p).age 的简写(语法糖)：先用 *p 把指针解引用成对象，再用点号取成员。箭头 -> 就是把这两步合成一步。所以 p->age = 20 改的就是 s.age，最后输出 20。

class 的成员默认是“私有”的，除了成员无法访问(如成员函数可访问)，必须写 public: 开启外部访问权限；而 struct 的成员默认就是公开的，不用写任何东西。

刚才那个例子，如果忘写 public:，就会这样：

#include <iostream>

class Student {
	int age;		// 没写 public:，age 默认是私有的
};

int main(){
	Student s;
	s.age = 18;		// 报错：私有成员，外面访问不到
	return 0;
}

编译报错（关键的那一行）：

error: 'int Student::age' is private within this context

struct#

struct 其实比 class 更早出现，C 语言里就有了，而 class 是 C++ 独有的。所以在 C 里你只能用 struct。

不过 C 的 struct 有两个限制，跟 C++ 不一样。

1. C 里声明对象要写 struct#

跟 6.1 枚举一模一样的套路：C 里声明变量要带关键字，C++ 不用。

#include <stdio.h>

struct Student {
	int age;
};

int main(){
	Student s;		// 报错：C 里要写 struct Student
	return 0;
}

编译报错：

error: unknown type name 'Student'; use 'struct' keyword to refer to the type

把 Student s; 改成 struct Student s; 就好了。在 C++ 里两种写法都合法，跟 6.1 的 enum 是同一个道理。

2. C 的 struct 没有成员函数#

#include <stdio.h>

struct Student {
	int age;
	int getAge(){ return age; }	// 报错：C 的 struct 里不能有函数
};

int main(){
	return 0;
}

编译报错：

error: expected ':', ',', ';', '}' or '__attribute__' before '{' token

所以成员函数是 C++ 的 struct 才有的语法，C 的 struct 只能装数据。

总结：在 C++ 里，struct 和 class 几乎可以互换，唯一区别就是默认访问权限（struct 公开、class 私有）。在 C 里，struct 更受限：声明要写 struct，而且不能有成员函数。

union#

struct 的每个成员各占各的内存；union 的所有成员共用同一块内存。

基础语法：

union 联合体名 {
	成员1;
	成员2;
	...
};

因为共用内存，所以一个 union 占的内存大小，等于它最大的那个成员的大小，而不是所有成员加起来。用 sizeof 验证一下：

#include <stdio.h>

union Data {
	int i;		// 4 字节
	double d;	// 8 字节
	char c;		// 1 字节
};

int main(){
	// 如果是C，你需要改成 sizeof(union Data)
	printf("%d", sizeof(Data));	// 输出 8：取最大成员的大小
	return 0;
}

运行结果：

8

三个成员加起来是 13 字节，但 union 只占 8 字节

共用内存还意味着：你写了 i，再从 c 的角度读同一块内存，读到的就是 i 的低字节被当成字符解释：

#include <stdio.h>

union Data {
	int i;		// 4 字节整数
	char c;		// 1 字节字符
};

int main(){
	Data d;
	d.i = 65;			// 写进整数 65
	printf("%c", d.c);	// 从字符角度看同一块内存：输出 A
	return 0;
}

运行结果：

A

因为 65 就是字符 'A' 的编码。你写进 int 的 65，从 char 的角度读同一块内存，看到的就是 'A'。

这里其实跟“大小端”有关(暂时不需要学)，换台电脑结果可能不一样。但只要知道：union 的成员共用内存，同一时刻只该用其中一个。

跟 struct 一样，C 里声明 union 对象也要写 union：

#include <stdio.h>

union Data {
	int i;
};

int main(){
	Data d;		// 报错：C 里要写 union Data
	return 0;
}

编译报错：

error: unknown type name 'Data'; use 'union' keyword to refer to the type

习题#

1. 猜输出#

不运行代码，猜猜下面程序输出什么，再运行验证：

#include <stdio.h>

union U {
	int i;
	char c;
};

int main(){
	U u;
	u.i = 97;
	printf("%c", u.c);
	return 0;
}

本题推荐最大时长：3分钟

答案

输出 a。97 是字符 'a' 的 ASCII 编码，union 的 i 和 c 共用内存，写进 97 再从 char 类型解析就是 'a'。

2. 学生信息求和#

定义一个结构体 Student，包含年龄 age 和分数 score 两个整数成员。输入两个整数，第一个是年龄，第二个是分数，输出它们的和。

输入的数字为整数，且 \(0 \le age \le 150\)、\(0 \le score \le 100\)。

本题推荐最大时长：8分钟

题目输入案例：18 90

输出结果案例：108

答案

讲解#

这题就一个考点：结构体的定义、声明对象、用点号访问成员。C 里记得声明对象要写 struct Student。

C#

#include <stdio.h>

struct Student {
	int age;		// 年龄
	int score;		// 分数
};

int main(){
	struct Student s;							// C 里声明要写 struct
	if(scanf("%d %d", &s.age, &s.score) != 2){	// 读入年龄和分数
		return 1;
	}
	printf("%d", s.age + s.score);	// 输出两者之和
	return 0;
}

C++#

#include <iostream>

struct Student {
	int age;		// 年龄
	int score;		// 分数
};

int main(){
	Student s;						// C++ 声明不用写 struct
	std::cin >> s.age >> s.score;	// 读入年龄和分数
	std::cout << s.age + s.score;	// 输出两者之和
	return 0;
}
