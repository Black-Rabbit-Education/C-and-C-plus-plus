3.3 switch语句

上一节我们学会了 if、else、else if，程序终于会"看情况做选择"了。不过不知道你有没有发现，用 else if 做"一个值对很多固定值"的选择时，写起来特别啰嗦：比如想输入 1~7 输出星期几，就得把 7 个 == 条件挨个写一遍（还记得 3.2 的 else if 链吗？）。这种场景，C 和 C++ 专门准备了 switch 语句：写起来更整齐，速度通常也更快。

switch 的语法#

先看 switch 的完整形式：

switch (表达式) {
	case 常量1:
		代码块1;
		break;
	case 常量2:
		代码块2;
		break;
	// case 可以有很多个
	default:
		兜底代码块;
}

程序执行到 switch 时，会先算出小括号里表达式的值，然后从上往下和每个 case 后面的常量做"相等"比较：匹配上了，就执行那个 case 下面的代码，一直执行到 break 为止；一个都没匹配上，就执行 default 里的代码（default 可以省略，省略后就是什么都不做，直接结束整个 switch）。

这里有两个限制要特别注意：第一，表达式和每次比较的 case 常量都必须是整数类型——int、char 都可以，但 float / double 不行，字符串更是还不行（这个后面章节才会学）；第二，case 后面必须跟常量，也就是编译期就能确定值的字面量，比如 3、'a'，不能是变量。『那我想判断变量怎么办？』——那说明这里不该用 switch，回去用 if 吧。

switch例子#

来看一个完整的例子：输入 1~7，输出对应星期几（输入的方法还记得吗？1.3 学的 scanf / std::cin）：

C#

#include <stdio.h>
int main(){
	int d;						// 星期几，1~7
	scanf("%d",&d);				// 输入一个整数
	switch (d) {
		case 1:
			printf("星期一\n");
			break;
		case 2:
			printf("星期二\n");
			break;
		case 3:
			printf("星期三\n");
			break;
		case 4:
			printf("星期四\n");
			break;
		case 5:
			printf("星期五\n");
			break;
		case 6:
			printf("星期六\n");
			break;
		case 7:
			printf("星期日\n");
			break;
		default:
			printf("输入错误\n");
	}
	return 0;
}

C++#

#include <iostream>
int main(){
	int d;						// 星期几，1~7
	std::cin >> d;				// 输入一个整数
	switch (d) {
		case 1:
			std::cout << "星期一\n";
			break;
		case 2:
			std::cout << "星期二\n";
			break;
		case 3:
			std::cout << "星期三\n";
			break;
		case 4:
			std::cout << "星期四\n";
			break;
		case 5:
			std::cout << "星期五\n";
			break;
		case 6:
			std::cout << "星期六\n";
			break;
		case 7:
			std::cout << "星期日\n";
			break;
		default:
			std::cout << "输入错误\n";
	}
	return 0;
}

运行后在程序窗口输入一个数字，比如 3，输出 星期三；输入 8，没有 case 匹配，落到 default，输出 输入错误。建议自己试试！再把几个 case 的顺序打乱，结果也不会变——switch 匹配只看值相不相等，与书写顺序无关。

贯穿：忘记 break 会怎样#

switch 和 if 有个很大的不同：if 执行完自己的块就结束了，而 switch 一旦命中某个 case，会从那里一路往下执行，直到遇到 break 或者 switch 结束才停，中间不会再做任何比较。这个行为叫贯穿（fall-through）。先看这个例子，猜猜输出什么：

#include <stdio.h>
int main(){
	int d = 2;
	switch (d) {
		case 1:
			printf("一\n");
		case 2:
			printf("二\n");
		case 3:
			printf("三\n");
		default:
		printf("默认\n");
	}
	return 0;
}

答案是输出三行：二、三、默认。d = 2 命中 case 2 后没有 break，就一直贯穿到了 switch 的末尾，连 default 也被执行了。这就是贯穿：匹配之后"一路走到底"。

忘记写 break 是 switch 最常见的错误：编译不会报错，程序也不会崩溃，只是会"多执行"后面的一堆代码。这种 bug 特别难排查，写完每个 case，检查一下末尾有没有 break。

贯穿绝大部分时候是 bug，但它也有一个合法用法，下一小节就是。

多个 case 共用一段代码#

有时候好几个值要做的事情一模一样，比如一周里 1~5 是工作日、6~7 是周末。与其把相同的代码写五遍，不如让它们共用一段——用贯穿正好能做到：

C#

#include <stdio.h>
int main(){
	int d = 6;					// 星期几，1~7
	switch (d) {
		case 1:
		case 2:
		case 3:
		case 4:
		case 5:
			printf("工作日\n");	// case 1~5 命中任何一个，都会贯穿到这里
			break;
		case 6:
		case 7:
			printf("周末\n");
			break;
		default:
			printf("输入错误\n");
	}
	return 0;
}

C++#

#include <iostream>
int main(){
	int d = 6;					// 星期几，1~7
	switch (d) {
		case 1:
		case 2:
		case 3:
		case 4:
		case 5:
			std::cout << "工作日\n";	// case 1~5 命中任何一个，都会贯穿到这里
			break;
		case 6:
		case 7:
			std::cout << "周末\n";
			break;
		default:
			std::cout << "输入错误\n";
	}
	return 0;
}

case 1 到 case 5 里没有代码也没有 break，它们只是五个"入口"：d 等于其中任何一个，都会贯穿到下面那句 printf。这比把同一句话写五遍干净多了。注意：共用的代码块结尾一定要有 break，否则还会继续贯穿到 default。

case 与 default 的小细节#

default 习惯放在最后，但放在中间也合法——只是如果它被命中又没有 break，同样会贯穿下去，所以放中间时记得写 break。另外，switch 的表达式只会被求值一次，而 else if 链的每个条件都会重新算一遍；如果表达式计算起来很"贵"（比如调用了一个函数），这算 switch 的一个优势。还有，case 的常量不一定是数字：字符字面量也可以，'a'、'+' 这种（字符本质就是整数，还记得 2.2 吗？），后面习题里的计算器就会用到。

switch 还是 else if？#

什么时候用 switch、什么时候用 else if？简单记：跟很多"固定值"做相等比较，用 switch；判断范围（a > 3）、组合条件（a > 1 && b < 10）、浮点数比较，或者分支很少，用 else if。switch 只能做"等于哪个值"的匹配，if 里可以放任意条件表达式。

性能技巧：else if 链是一个个比较过去的，最坏情况要把所有条件都试一遍（3.2 教过你把最常触发的条件放前面，就是在减小这个"平均比较次数"）；而 switch 只要 case 的常量比较集中，编译器往往会把它优化成一张跳转表（jump table），一次匹配就能直接跳到目标分支，跟 case 的个数关系不大。所以看到一长串"等于某个固定值"的判断，直接换 switch，把优化交给编译器。

switch 的花括号也是一个域#

3.1 我们学过：一对花括号就是一个块（域）。switch 的大花括号同样是块。但要小心：每个 case 并不是独立的域，整个 switch 的花括号才是一个域。所以在 case 里声明的变量，后面的 case 也能"看见"它，而且从后面的 case 跳进来会跳过它的初始化。C++ 里这直接是编译错误：

C++（错误示范）#

#include <iostream>
int main(){
	int d = 1;
	switch (d) {
		case 1:
			int t = 10;			// 在 case 里直接声明变量
			std::cout << t << "\n";
			break;
		case 2:					// 从 case 2 跳进来，会跳过 t 的初始化 → 编译错误
			std::cout << "二\n";
			break;
	}
	return 0;
}

正确做法：需要临时变量时，用一对花括号把那个 case 包起来——它就有了自己的域（这就是 3.1 的知识）：

C++（正确示范）#

#include <iostream>
int main(){
	int d = 1;
	switch (d) {
		case 1: {
			int t = 10;			// {} 让这个 case 拥有自己的域，t 出不去
			std::cout << t << "\n";
			break;
		}
		case 2: {
			int t = 20;			// 和 case 1 的 t 是不同域，同名也不冲突
			std::cout << t << "\n";
			break;
		}
	}
	return 0;
}

在 C（C17）里跳过的代码能编译通过，但变量会带着没有初始化的垃圾值被使用，同样是坑。所以无论 C 还是 C++，case 里要声明变量，就用 {} 包起来。

常见错误#

1. 忘记 break（最常见）#

switch (d) {
	case 1:
		printf("一\n");
	case 2:				// d 等于 1 时也会执行到这里！
		printf("二\n");
		break;
}

每个 case 写完，检查末尾有没有 break；default 放最后时可以不用写（走到它时 switch 已经结束了）。具体原理见上面"贯穿"那一节。

2. case 后面写了变量#

int n = 3;
switch (d) {
	case n:					// 错误！case 后面必须是常量
		printf("三\n");
		break;
}

把这行放进 main 里编译，会报 case label does not reduce to an integer constant。想比较变量？那说明这里不该用 switch，回去用 if 吧。

3. case 的常量重复#

switch (d) {
	case 1:
		printf("一\n");
		break;
	case 1:				// 错误！case 1 已经出现过了
		printf("壹\n");
		break;
}

同样的常量出现两次，放进 main 里编译会报 duplicate case value。

4. switch 里塞了浮点数或字符串#

float f = 1.5;
switch (f) {				// 错误！switch 只能判断整数类型
	...
}

放进 main 里编译会报 switch quantity not an integer。浮点数要比较大小用 if；字符串比较我们后面章节再学。char 却完全可以——它本质就是整数。

小结#

这一节我们学会了 switch：一个整数表达式的值跟多个常量匹配，命中后一路执行到 break；贯穿（fall-through）既是它最大的坑，也是"多个 case 共用一段代码"的合法技巧；还知道了 switch 和 else if 怎么选，以及 case 里要声明变量就用 {} 包起来。到这里，程序的"选择"能力就完整了：条件复杂、分支少，用 if 家族；分支多、都是固定值，用 switch。

下一节我们将学习循环语句（while、do-while、for），让程序能反复执行某段代码——选择加循环，你就能写出真正"活"的程序了。(如果没事干，可以去洛谷、力扣等算法平台找点分支结构的题练练手，switch 类的题不多，关键是别踩贯穿这个坑。)

2. 成绩等级#

输入一个成绩 score（\(0 \le score \le 100\)），用 switch 输出等级：90~100 输出 A，80~89 输出 B，70~79 输出 C，60~69 输出 D，0~59 输出 E。

提示：switch 只能判断"等于某个值"，不能判断范围。想想 score / 10 能得到什么，再用它做 switch 的表达式。

本题推荐最大时长：10分钟

题目输入案例：85

输出结果案例：B

答案

C#

#include <stdio.h>
int main(){
	int score;					// 成绩
	scanf("%d",&score);			// 输入成绩
	switch (score / 10) {		// 整数除法，把 0~100 压成 0~10
		case 10:				// 100 分
		case 9:				// 90~99
			printf("A\n");
			break;
		case 8:
			printf("B\n");
			break;
		case 7:
			printf("C\n");
			break;
		case 6:
			printf("D\n");
			break;
		default:				// 0~59，以及所有不该出现的输入
		printf("E\n");
	}
	return 0;
}

C++#

#include <iostream>
int main(){
	int score;					// 成绩
	std::cin >> score;			// 输入成绩
	switch (score / 10) {		// 整数除法，把 0~100 压成 0~10
		case 10:				// 100 分
		case 9:				// 90~99
			std::cout << "A\n";
			break;
		case 8:
			std::cout << "B\n";
			break;
		case 7:
			std::cout << "C\n";
			break;
		case 6:
			std::cout << "D\n";
			break;
		default:				// 0~59，以及所有不该出现的输入
		std::cout << "E\n";
	}
	return 0;
}

5. 简易计算器#

先输入一个运算符（+ - * / 之一），再输入两个整数，输出运算结果；运算符不是这四个字符时输出 运算符错误。题目保证输入不会出现除 0。

本题推荐最大时长：15分钟

题目输入案例：* 4 5

输出结果案例：20

答案

C#

#include <stdio.h>
int main(){
	char op;						// 运算符
	int a, b;					// 两个数字
	scanf(" %c %d %d",&op,&a,&b);	// %c 前面的空格：跳过输入里残留的换行
	switch (op) {
		case '+':
			printf("%d\n", a + b);
			break;
		case '-':
			printf("%d\n", a - b);
			break;
		case '*':
			printf("%d\n", a * b);
			break;
		case '/':
			printf("%d\n", a / b);	// 整数除法，题目保证 b 不为 0
			break;
		default:
			printf("运算符错误\n");
	}
	return 0;
}

C++#

#include <iostream>
int main(){
	char op;						// 运算符
	int a, b;					// 两个数字
	std::cin >> op >> a >> b;		// C++ 不需要 C 那样的空格技巧
	switch (op) {
		case '+':
			std::cout << a + b << "\n";
			break;
		case '-':
			std::cout << a - b << "\n";
			break;
		case '*':
			std::cout << a * b << "\n";
			break;
		case '/':
			std::cout << a / b << "\n";	// 整数除法，题目保证 b 不为 0
			break;
		default:
			std::cout << "运算符错误\n";
	}
	return 0;
}
