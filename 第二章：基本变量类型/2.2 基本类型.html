2.2 基本类型

变量只有几种是完全不够用的，我们需要更多对于变量的了解！

基本变量类型表#

我们将讲解所有基本变量类型与它的占位符

有符号和无符号#

在开始之前，我们先要了解什么是有符号什么是无符号。

你可以直接理解为有符号的类型就是变量可以是负数，无符号的，变量就不能是负数。

我们用signed表示有符号，unsigned表示无符号。

C语言#

无类型#

这个类型暂时不需要学，只需要知道即可

整数类型#

无符号整数类型#

无符号类型不能存储负数，但可以存储更大的正数。

浮点类型#

浮点类型用于存储小数（带小数的数字）。

如果你需要只保留几位小数，可以将占位符修改为：%.nf。

用小数点表示我们要保留小数后几位，将\(n\)替换为你想要保留多少位数字，比如保留三位小数输出：printf("%.3f",10);

运行结果就会输出：10.000

字符类型#

字符类型用于存储单个字符。

布尔类型#

布尔类型用于存储"真/假"值，C语言使用此变量类型需要在代码顶部添加代码#include <stdbool.h>，而C++则不需要。

综合示例#

#include <stdio.h>
#include <stdbool.h>	// 如果使用C++运行本代码，可以去掉此行代码

int main()
{
    int age = 18;
    float height = 175.5f;
    double weight = 65.25;
    char grade = 'A';
    unsigned int score = 100;
    bool isStudent = true;

    printf("年龄：%d\n", age);
    printf("身高：%.1f\n", height);
    printf("体重：%.2lf\n", weight);
    printf("等级：%c\n", grade);
    printf("分数：%u\n", score);
    printf("是否为学生：%d\n", isStudent);
    printf("int 占 %d 个字节\n", sizeof(int));

    return 0;
}

C++#

C++有C的所有语言内置类型，其中的bool还不需要添加新的代码，可以直接使用。

C++在C的基础上，添加了更多内置类型。

字符类型#

C++ 的宽字符类型也是语言内置类型（C 中它们是标准库 typedef，需要包含头文件）。

获取变量类型的信息#

变量类型占用内存大小#

我们可以使用函数sizeof来获取变量占用内存大小，只有一个参数，参数填入变量类型，它会返回一个整数，表示该类型占用内存多少字节。

比如：

#include <stdio.h>
int main()
{
    printf("int占用内存大小：%zu个字节\n", sizeof(int));

    return 0;
}

将上述代码放在你的项目中运行，你可以看见输出int占用内存大小：4字节，具体每一个机器或编译器的占用可能不一样，需要大家自己尝试每一个类型占用大小。

变量的最大值和最小值#

每个电脑上因为不同的占用内存大小，所以变量的最大值和最小值也需要自行测试最好。

每种内置类型都有一个能表示的最大值和最小值的方法。

注意：无符号类型的最小值恒为 0，所以没有 Uxx_MIN ；char、signed char、unsigned char 是三种不同的类型，char 的边界取决于编译器把它当作有符号还是无符号（用 CHAR_MIN / CHAR_MAX 一查便知）。

浮点类型#

想要获取浮点类型的最大值和最小值，需要最顶上添加一行代码 #include <float.h> ，要注意它们表示的是"最小正数"和"最大绝对值"：

浮点数没有"负方向最小值"宏：想打印"最负"的数用 -FLT_MAX；输出建议用 %e（科学计数法占位符），否则小数位数会很夸张。

示例#

#include <stdio.h>
#include <float.h>	// 可以添加在这里
int main()
{
    printf("int: %d ~ %d\n", INT_MIN, INT_MAX);
    printf("unsigned int: 0 ~ %u\n", UINT_MAX);
    printf("long long: %lld ~ %lld\n", LLONG_MIN, LLONG_MAX);
    printf("float: %e ~ %e\n", -FLT_MAX, FLT_MAX);

    return 0;
}

运行结果具体数值可能有差异：

int: -2147483648 ~ 2147483647
unsigned int: 0 ~ 4294967295
long long: -9223372036854775808 ~ 9223372036854775807
float: -3.402823e+38 ~ 3.402823e+38

(如果你的电脑报错没有这些东西，可以最顶上添加一行#include <limits.h>)

常量指定类型#

有时候，计算机不能准确猜出你想要的变量类型是什么，我们就需要特定的符号或者添加特定的修饰符来

为什么要指定#

直接写在代码里的数字和文字叫作常量（也叫字面量）。计算机对每个常量都有一个默认的类型猜测：整数默认是int，小数默认是double，字符用单引号、字符串用双引号。当默认猜测不符合你的需要时（比如想要单精度、想要长整型），就在常量后面加上对应的后缀。

无后缀类型#

整数常量的后缀#

后缀字母不区分大小写，但小写的l和数字1长得太像，建议一律用大写L。

整数常量的进制前缀#

除了十进制，整数常量还可以用前缀直接写其他进制，这在很多场合（如位运算）非常有用：

进制前缀和后缀可以同时使用，比如0xFFu就是无符号的 255（十六进制）。

浮点常量的后缀#

其实整数也可以写成带小数点的样子，比如3.0，但那是double类型，不是整数。

科学计数法#

小数常量还可以用科学计数法书写：一个数字、一个字母e（或E）、一个指数。比如1.5e3的意思是 1.5 × 10 的 3 次方，也就是 1500。

规则：e前面必须有数字；e后面必须是整数（可以带+或-号）；类型后缀照常加在最后面。科学计数法最适合表示非常大或非常小的数字，比如物理常数。

#include <stdio.h>
int main(){
	printf("%e\n", 12345.678);	// 输出 1.234568e+04
	printf("%f\n", 1.5e3);		// 输出 1500.000000
	printf("%E\n", 1e-3);		// 输出 1.000000E-03
	return 0;
}

对应地，%e本身就是用科学计数法打印浮点数，%g会自动在普通小数和科学计数法之间选择更短的那个。

支持十六进制浮点数，例如0x1.8p3（用%a输出），日常很少用到，知道即可。

字符与字符串的前缀#

字符和字符串常量也可以用前缀指定宽字符类型：

综合示例#

#include <stdio.h>
int main(){
	printf("%d\n", 100);			// int
	printf("%u\n", 100u);			// unsigned int
	printf("%ld\n", 100L);			// long
	printf("%lld\n", 100LL);		// long long
	printf("%f\n", 3.14f);			// float
	printf("%lf\n", 3.14);			// double
	printf("%Lf\n", 3.14L);		// long double
	return 0;
}

注意给long double打印要用大写的%Lf，小写的%lf是double用的。

不指定的后果#

如果常量超出默认类型的范围，就会出问题。比如100000000000（一千亿）在 32 位编译器上超过了 int 的最大值（约 21 亿），直接写会得到溢出警告甚至错误结果，写100000000000LL就不会有问题。这就是指定类型在实际中的意义。

精度丢失#

我们在1.3 输入与输出概述的习题2中，尝试过将一个小数输入给一个整数，会发现只保留了整数。

这是因为它发生了精度丢失，简单来说就是，int类型只有整数的空间，没有留给小数的空间，而多的小数，无处可去便丢失了，这便是精度丢失。

当然，精度丢失并不一定是坏事，有时候我们可以利用精度丢失来完成我们想要的事情。

类型转换#

我们常常需要进行类型转换，比如一个整数转换成小数类型，或者一个布尔类型转换成整数类型进行加减。

隐式类型转换（自动）#

有些转换是编译器自动完成的，不需要我们写任何代码：

最容易踩的坑：两个整数相除，结果还是整数（小数被截断）。5 / 2 的结果是 2 而不是 2.5；想让结果是小数，至少让其中一个变成浮点，例如 5.0 / 2。

隐式转换的案例#

如果运行后数据结果与预想中的不一样，很有可能就是精度丢失，以下给出了一些隐式转换的案例：

#include <stdio.h>
int main(){
	int a = 3.99;			// double 转 int：小数被丢弃，a = 3
	double b = a;			// int 转 double：b = 3.0
	int c = 5 / 2;			// 整数除法：c = 2（不是 2.5！）
	unsigned int d = -1;		// int 转 unsigned：负数变成很大的正数
	printf("a=%d b=%lf c=%d d=%u\n", a, b, c, d);
	printf("'A' + 1 = %d\n", 'A' + 1);	// char 参与运算会提升为 int：65+1=66
	return 0;
}

运行结果：a=3 b=3.000000 c=2 d=4294967295 和 'A' + 1 = 66，你可以对照自己的预期看看哪些地方"不一样"。

强制类型转换#

当隐式转换不符合我们的需要时，可以自己写出来，明确告诉编译器转成什么类型，这叫强制类型转换（也叫显式转换）。

C 语言的写法是在值前面加一对括号写上类型：(类型)值。例如：

#include <stdio.h>
int main(){
	double d = (double)5 / 2;	// 先把5转成double，再除以2，结果是2.5
	int a = (int)3.99;			// 强制转成int，小数丢掉，结果是3
	printf("%lf %d", d, a);
	return 0;
}

综合示例#

#include <stdio.h>
int main(){
	int a = 3.99;			// 隐式转换，小数被丢弃：a = 3
	double b = a;			// 隐式转换，整数变小数：b = 3.0
	int c = (int)3.99;		// 强制转换：c = 3
	double d = (double)5 / 2;	// 强制转换后相除：d = 2.5
	int e = 5 / 2;			// 整数除法：e = 2
	printf("%d %lf %d %lf %d", a, b, c, d, e);
	return 0;
}

输出：3 3.000000 3 2.500000 2

关于 char 与整型的转换#

char 的本质是一个较小的整数（存放的是字符的ASCII编码值，这个可以自己随手百度一下看看编码），所以它可以和整型互相转换，这也是前面表格里"char 参与运算会提升为 int"的原因。

char 与 int 互相转换#

#include <stdio.h>
int main(){
	char ch = 'A';
	int n = ch;			// char 自动提升为 int：n = 65
	printf("作为整数输出：%d\n", n);	// 65
	printf("作为字符输出：%c\n", n);	// A（整数 65 按字符打印）
	n = 98;
	printf("%c\n", n);		// b（98 是 'b' 的编码）
	ch = 65 + 1;			// 整数转回 char：'B'
	printf("%c\n", ch);		// B
	return 0;
}

运行结果：

作为整数输出：65
作为字符输出：A
b
B

同一个值，用 %d 打印就是数字，用 %c 打印就是字符。

建议记住ASCII编码的所有数字和英文字母对应的编码十进制值。(其他的可以进行进制转换)

注意#

如果整数超出了 char 能表示的范围（有符号时约为 -128~127），转成 char 时只会保留低 8 位，结果可能出乎意料：

#include <stdio.h>
int main(){
	char ch = 200;		// 超出 char 的范围
	printf("%d\n", ch);	// 某些编译器上会得到 -56
	return 0;
}

所以做这种转换前，最好先确认数值在 char 的取值范围内。

转义字符#

有些字符没法直接写进代码里（比如换行、制表符、双引号本身），或者写出来容易引起歧义，这时就要用到转义字符：一个反斜杠\开头，后面跟一个字母或数字。

常见的转义字符#
示例#
#include <stdio.h>
int main(){
	printf("第一行\n第二行\n");		// 换行
	printf("a\tb\n");				// Tab 制表
	printf("他说：\"你好\"\n");		// 双引号
	printf("路径：C:\\Users\n");		// 反斜杠
	printf("\x48\x49\n");			// 十六进制转义：输出 HI
	return 0;
}

运行结果：

第一行
第二行
a	b
他说："你好"
路径：C:\Users
HI
注意#

\n 是一个字符，不是反斜杠加字母 n 两个字符；转义字符也可以用在字符常量中，'\n'、'\t' 都是合法的 char。想在字符串里输出反斜杠本身，必须写两个反斜杠。

关于空值#

零、空字符、数字零字符、空格、换行……听起来都是"空"，它们的区别却是初学者最容易搞混的地方。它们的本质区别是：编码值不同，含义不同。

最容易混淆的是这三兄弟：0、'\0'、'0' 前两个编码都是 0（编码上的零），但'\0'是"没有字符"的意思；而'0'是一个真实的字符，编码是 48，跟零没有任何数值上的关系。

演示一下#

#include <stdio.h>
int main(){
	printf("%d\n", 0);		// 整数 0
	printf("%d\n", '\0');	// 空字符的编码：0
	printf("%d\n", '0');	// 字符'0'的编码：48
	printf("%d\n", ' ');	// 空格的编码：32
	printf("%d\n", '\n');	// 换行的编码：10
	printf("A\0B\n");		// 字符串遇到\0就结束：只输出 A
	return 0;
}

运行结果：

0
0
48
32
10
A

最后一行只输出了 A：字符串在内存里其实是A、\0两个字符，\0是结束标志，所以 printf 输出到它为止，后面的 B 不会显示（它还在内存里，只是不再被当作字符串的内容）。

实用小技巧#

判断一个字符是不是数字时，用字符本身比较比用编码数字更清晰：c >= '0' && c <= '9'，而不是写 c >= 48 && c <= 57，这样可读性高得多，也不容易记错编码。

习题#

1.输出两个数相加#

输入两个数，用空格分开，然后输出两数相加的结果。

所有输入的数字\(>-10^{11}且<10^{11}\)

题目输入案例：9999999999 9999999999

输出结果案例：19999999998

本题推荐最大时长：5分钟

答案

讲解#

本题主要考察对数据大小的把握，答案不唯一，不同系统可能略有不同。

\(10^{10}\)大于int的最大值，所以发生了精度丢失，结果超出预期，所以我们需要用更大的变量类型

C#

#include <stdio.h>
int main()
{
    long long a,b;	// 部分系统或许可以用long即可
    scanf("%lld %lld",&a,&b);
    printf("%lld",a+b);
    return 0;
}

C++#

#include <iostream>
int main()                
{ 
	long long a,b;
    std::cin >> a >> b;
    std::cout << a+b;
    return 0;
}

2.输出三角形面积#

输入两个数，用空格分开，第一个数为三角形的底边，第二个数为三角形的高。

所有输入的数字\(>-2^6且<2^6，且最多两位小数\)。

输出结果保留三位小数。

题目输入案例：3 5

输出结果案例：7.500

本题推荐最大时长：5分钟

答案

讲解#

本题同样考察对数据的把握，同时多了一个保留小数的考点。

C#

#include <stdio.h>
int main()
{
    float a,b;
    scanf("%f %f",&a,&b);
    printf("%.3f",a*b/2);
    return 0;
}

C++#

#include <iostream>
int main()                
{ 
	float a,b;
    std::cin >> a >> b;
    printf("%.3f",a*b/2);	// 我们暂时还没学std::cout 进行格式输出，所以可以用C的方式完成任务
    return 0;
}

3.转换成大写#

输入一个小写字母，需要你输出输入的字母，然后换行输出大写字母。

题目输入案例：a

输出结果案例：

a
A

本题推荐最大时长：10分钟

答案

讲解#

本题考察对转义字符的把握，以及对ASCII编码表、类型转换的把控。

C#

#include <stdio.h>
int main()
{
    char a;
    scanf("%c",&a);
    printf("%c\n%c",a,a-32);	// 直接观察ASCII表可以发现大小写字母刚好差32，我们直接减去即可。
    return 0;
}

C++#

#include <iostream>
int main()                
{ 
	char a;
    std::cin >> a;
    // 我们如果忘掉了具体大小，也可以用这种直接让程序自己计算大小写距离的方法
    std::cout << a << '\n' << (char)(a-('a'-'A'));// 最后记得转换类型，不然会被隐式转换成数字类型
    // 这种方法还会考验你对隐式转换的了解程度
    return 0;
}
